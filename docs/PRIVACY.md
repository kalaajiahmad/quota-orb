# Privacy

Codex supplies aggregate account limits through its documented local app-server. The experimental Claude integration receives documented status-line events and saves only numeric quota fields and receipt time. It does not read conversations or open authentication files. The firmware receives rendered pixels, sequence numbers, and checksums. No remote backend, analytics service, or WiFi connection is included.

Local operation creates aggregate quota logs, runtime status, and preview images. These may reveal usage patterns. They are ignored by Git and are not suitable for automatic publication. Do not share raw diagnostics, full flash backups, environment files, or authentication files.

The public source tree uses synthetic test data and showcase imagery, relative paths, neutral project authorship, and regenerated CAD exports. Manufacturer downloads, local validation logs, firmware backups, native working scenes, and host build products are excluded.

A local pre-publication audit checks repository files and archive members for common credential formats, personal home-path patterns, private runtime folders, and embedded path metadata. It is a preventive check, not a guarantee that arbitrary future contributions contain no sensitive material. Review changes before publishing.
